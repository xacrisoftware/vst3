# LoFi Crusher

Минимальный VST3 bitcrusher для FL Studio.

## Как получить плагин без установки инструментов

1. Создай пустой репозиторий на GitHub.
2. Загрузи туда все файлы этой папки.
3. Открой вкладку **Actions**, выбери **Build VST3**, нажми **Run workflow**.
4. После сборки открой результат запуска и скачай artifact `LoFiCrusher-VST3`.
5. Распакуй архив. Папку `LoFi Crusher.vst3` положи, например, в `C:\VST\`.
6. В FL Studio добавь `C:\VST\` в `Options > Manage plugins > Plugin search paths` и нажми `Find installed plugins`.

Параметры: Bit Depth, Downsample, Mix.
